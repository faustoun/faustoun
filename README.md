# Разработчик приложений и интеграций Bitrix24

Разрабатываю приложения для Bitrix24, интеграции через REST API и инструменты автоматизации бизнес-процессов. Работаю с облачными и коробочными решениями, серверной логикой, интерфейсами и эксплуатацией приложений на Linux.

В проектах уделяю внимание правам доступа, проверке данных, защите от повторных операций и возможности восстановить состояние после сбоя. Использую OpenAI Codex в разработке, от уточнения требований и проектирования до проверки кода и подготовки внедрения.

## Избранные проекты

### Корреспонденция в Bitrix24

Приложение для регистрации входящих и исходящих писем, присвоения номеров и связи переписки с CRM. Серверная обработка, локальное хранение состояния и проверка операций перед записью в портал.

**Стек** · JavaScript, Node.js, SQLite, Bitrix24 REST API, OAuth.

[Разбор проекта](projects/bitrix24-correspondence.md)

### Контроль смен и передача лидов КЦ

Сервис для учёта состояния операторов и передачи активных лидов и незавершённых CRM-дел при смене ответственного. Предварительная диагностика, режим dry-run и отдельный интерфейс проверки.

**Стек** · JavaScript, Node.js, SQLite, Bitrix24 REST API.

[Разбор проекта](projects/call-center-shift-handover.md)

### Интеграция МегаФон × Bitrix24

Сервис интеграции виртуальной АТС и SIM-телефонии с CRM: регистрация входящих, исходящих и пропущенных звонков, привязка к клиенту и открытой карточке, загрузка записей разговоров. Журнал операций, восстановление очереди и независимая проверка результата защищают обработку от повторных записей.

**Стек** · JavaScript, Node.js, SQLite, API МегаФона, Bitrix24 REST API, OAuth, Linux/systemd.

[Разбор проекта](projects/megafon-bitrix24.md)

### Корпоративная RPG внутри Bitrix24

Кооперативная браузерная RPG в интерфейсе корпоративного портала. Выбор классов, пошаговые бои, исследование комнат, задания с вариантами действий, инвентарь и награды. Игровые правила вынесены в отдельный TypeScript-пакет; Vue-интерфейс работает с состоянием партии и пользовательской сессией.

**Стек** · TypeScript, Vue 3, Pinia, Vue Router, Vite, Socket.IO, Bitrix24.

[Разбор проекта](projects/corporate-rpg.md)

### Marketing Experiment Agent

Инженерный проект анализа маркетинговых данных и планирования экспериментов. Импорт CSV, программные расчёты метрик, роли аналитика и рецензента, карточки экспериментов с подтверждением пользователем и восстановление выполнения по checkpoint.

**Стек** · TypeScript, Node.js, Fastify, React, SQLite, JSON Schema.

[Разбор проекта](projects/marketing-experiment-agent.md)

## С чем работаю

- **Приложения и интеграции** — REST API, OAuth, вебхуки, события, смарт-процессы и бизнес-процессы Bitrix24.
- **Backend и данные** — JavaScript, TypeScript, Node.js, Fastify, SQL, SQLite и PostgreSQL.
- **Frontend** — Vue 3, Pinia, Vue Router, Vite. Для совместимых интерфейсов Bitrix24 использую B24 UI.
- **Эксплуатация** — Linux, Nginx, systemd, SSH/SFTP, подготовка развёртывания и отката.
- **Проверка** — Node.js test runner, Vitest, проверка типов, интеграционные и пользовательские сценарии.

## Подход к работе

1. Уточняю бизнес-задачу, ограничения и критерии приёмки.
2. Проектирую модель данных, интеграции, права и обработку ошибок.
3. Реализую изменения небольшими проверяемыми этапами.
4. Проверяю расчёты, повторные операции, ошибки доступа и восстановление после сбоя.
5. Готовлю инструкции, резервирование и проверку результата внедрения.

Рассматриваю задачи по разработке приложений и интеграций Bitrix24, автоматизации CRM и развитию внутренних сервисов.
