# Marketing Experiment Agent

## Задача

Помочь пользователю разобрать рекламную статистику, сформировать проверяемую гипотезу и организовать следующий эксперимент в заданных ограничениях.

## Реализованные части

- Проекты и импорт CSV с проверкой структуры и метаданных.
- Программный расчёт CTR, CPC, CVR и CPA с обработкой нулевых знаменателей.
- Контракты инструментов и состояния процесса анализа.
- Логические роли аналитика и рецензента.
- Предварительный просмотр и подтверждение создания карточки эксперимента.
- Сохранение состояния, версий данных и checkpoint для возобновления.
- React-интерфейс, локальные тестовые данные и демонстрационные сценарии.

## Архитектура

TypeScript-приложение с Fastify API и React-интерфейсом. SQLite хранит состояние. Типизированные и проверяемые контракты связывают набор данных, расчёты, предложение, рецензию и пользовательское подтверждение. Авторизация записи карточки проверяется контроллером приложения.

## Инженерные решения

Языковая модель выбирает допустимый следующий шаг и формирует объяснение. Численные показатели рассчитываются программными инструментами. Сохранение версий и ключей повторяемых операций помогает учитывать повторный клик, прерывание шага и изменение входных данных.

## Демонстрационные сценарии

1. Анализ корректного набора и формирование плана эксперимента.
2. Недостаточная выборка и запрос дополнительных данных.
3. Ошибочное тестовое предложение, отклонение рецензентом и исправление.

В материалах проекта различаются mock/replay, локальные проверки и обращения к модели. Статус полного сценария с реальной LLM определяется отчётом соответствующего запуска. Портфолио описывает реализованный инженерный контур без обещаний улучшения рекламных показателей.

**Технологии** · TypeScript, Node.js, Fastify, React, SQLite, JSON Schema, CSV, автоматизированные проверки.
